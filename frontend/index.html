How TokenLine Operates

From individual telemetry events to reconstructed forensic trees, explore the 5 stages of token tracking.

01

Capture

Every token_issued, token_refreshed, and token_used event enters the pipeline as a schema-valid record.

  • Validates JSON schema against schema/event.schema.json
  • Rejects raw credentials or exposed JWTs immediately
02

Correlate

Parent/child links are resolved; token_family chains (A → B → C) are reconstructed dynamically as rotation occurs.

  • Propagates stable family IDs from roots to child successors
  • Marks parent tokens as rotated in memory and database
03

Detect

Reuse of an already-rotated token, replay, concurrent use, and impossible travel conditions are flagged.

  • Flags refresh-token reuse on already-rotated credentials
  • Highlights compromised lineage nodes in red
04

Investigate

Every flagged condition carries its full chain and context, ready for a security analyst or alerting engine.

  • Exposes exact rotation timestamps and reuse attempt events
  • Visualizes complete ancestor and descendant graphs
05

Evolve

The correlation model extends as new event types and detection rules are added, without breaking existing families.

  • Additive design ensures backwards compatibility
  • Independent token families remain strictly isolated

About TokenLine

Mission & Core Problem

Modern authentication pipelines log hundreds of disconnected events across multiple servers. When a refresh token is stolen and replayed, security investigators are left searching through flat, unlinked audit logs.

TokenLine introduces real-time token family correlation. It maintains parent/child rotation lineages ($A \rightarrow B \rightarrow C$), identifies refresh-token reuse on already-rotated tokens, and renders the complete lifecycle into an investigable visual timeline.

Synthetic Security Boundary

To ensure safety and privacy, TokenLine operates solely with salted cryptographic hashes and deterministic synthetic attack simulators. No production credentials, live tokens, or external network infrastructures are ever touched.

Key Capabilities

  • Token-Family Correlator: Reconstructs $A \rightarrow B \rightarrow C$ chains and flags reuse conditions.
  • Local Attack Simulator: 5 deterministic scenarios (Replay, Refresh-Reuse, Revoked Token, Concurrent Use, Impossible Travel).
  • Technical Wireframe Visualization: Real-time orbital globe and directional family graphs.
